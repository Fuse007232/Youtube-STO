# YouTube Shorts · Live Timing

Privates Dashboard für **Bra1nrotvault** und **Granny Aura**: beide Kanäle auf einen Blick,
24h-Duell im F1-Timing-Tower-Stil, Rennverlauf und Top-Shorts-Rangliste.

- Projektplan & Anleitungen: [`docs/PLAN.md`](docs/PLAN.md)
- Architektur & „Neues Widget hinzufügen“: [`CLAUDE.md`](CLAUDE.md)

## Befehle

```bash
npm install        # Abhängigkeiten installieren
npm run dev        # Entwicklungs-Server auf http://localhost:3000
npm run build      # Produktions-Build (macht auch Vercel)
npm run lint       # Code-Stil prüfen
npm run typecheck  # TypeScript prüfen
npm test           # Tests der Rechenlogik
```

Ohne Umgebungsvariablen läuft die App mit **Beispieldaten** (`DATA_SOURCE=mock`).
